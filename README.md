# Hetherington's — Day 7 SITEPRO Frontend

## Direction
**The Pollard Street Local — Manchester Pub Editorial**

The design is intentionally pub-first and sport-second: warm neighbourhood character, condensed Manchester poster typography, dark coal/green surfaces, warm amber accents, and restrained matchday graphics.
